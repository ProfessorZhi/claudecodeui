## 方法与限制（如实记录）

1. **花费是估算**。`estimateRealtimeCostCny` 是出货的估算公式（文本入 0.0015、音频入 0.006、文本出 0.0045 CNY / 1k token），账单以官方为准；这里报的是与出货花费守卫**同一个**读数，不是发票。
2. **音频是合成语料**。长静音/停顿是低幅粉噪 stand-in，不是真人环境录音；现实环境的底噪频谱、非平稳噪声（键盘、空调、人声）都可能被上游 VAD 判为语音，本运行**没有**覆盖那些。
3. **`usage.input_tokens_details` 是整条连接的累计值**（出货 transport 头注确认，已对过真实账单行），不是每次 response 的增量。所以「静音期间 token」报的是窗口内最后一次减去窗口前最后一次的**差值**，并附上窗口内 `response.done` 的 usage 原文供核对。
4. **上游抽样**。真实上游逐条只跑一次，条目边界与工具调用存在非确定性（同一段音频两臂读数本来就不同是读数的内容之一，不是噪声）。
5. **R-3 只报读数，不设门槛**。「决策分布」是模型在带 RunDigest 草案指令下的行为，不构成对错判断；指令措辞见 `experiments/voice-realtime-continuous-keepalive/corpus.json` 的 `r3.instructions`。

原始帧与逐条判读在运行目录的 `journal/<连接 id>.jsonl` 与 `<连接 id>.frames.json`；本报告的每一行都能在那两个文件里对上。运行目录：`/tmp/keepalive-full`。
