API Documentation

CloudCLI runs a local HTTP server that serves its web interface. This page is the place for documentation of the HTTP API that server exposes.

Authentication

Programmatic requests authenticate with an access token created in the application's settings. Send the token with each request, and revoke it from the same place when it is no longer needed.

Tokens are stored as hashes: the server keeps only a hash and a short prefix, so a token is treated as a secret that is displayed when it is issued and never stored in the clear.

Retired surfaces

The legacy programmatic agent endpoint and the plaintext key mechanism it used have been retired. The server no longer mounts them, and this page no longer documents them; the sections and examples that described them have been removed rather than kept around.

The retired surface is gone from the running server: its routes are not registered, so a request to them is answered by the same static-asset fallback as any other unknown path.
