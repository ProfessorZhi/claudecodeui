## 背景

语音输入链路今天只支持 OpenAI-compatible 一种识别服务，且协议形状被硬编码在四处（两跳各自的请求构造与响应解析）。两条路径的响应容忍度已经分叉：同一个上游异常在直连路径上报错，在代理路径上会被当成一段转写文本填进 composer。服务之间的能力差异（内联请求预算、计费单位、是否承认提示词、停顿线索对该识别器是破坏性还是有用）在代码里没有任何地方可以表达。

人 yale 2026-09-22 裁定 ADR-004 通过（status: accepted），并逐条裁定其七条开放问题：接受边界探针红时的退化（服务端代理保持 OpenAI-compatible 专用）；语义等价轴拆两半（质量人读、安全机检）；隐私告知放设置页不弹窗；浏览器持服务商密钥可接受并支持服务端环境变量作为第二条键来源；判据与实验记录的分界维持；路径 (a) 授权一次有界尝试并预先授权 (b) 作为回落。

## 范围

- 识别服务的差异由「适配器缝 + 能力声明」表达，不由配置字段表达。
- 适配器环境中立：同一份实现服务浏览器（直连）、Node 服务端（代理）、命令行三处。
- 命令行与库一级的验证先于服务端与前端接线：--dry-run 零成本验证请求构造，--offline 回放使验证可以离线跑。
- 三处既有缺口按能力声明驱动修复：转写路由的 MIME 白名单、请求预算的分层上限、健康检查的单一真相源。
- 裁剪决策改由能力声明驱动，默认行为不变。

## 非目标

- 不做实时或双向语音：oneShot 在第一版只允许 true。
- 不做 TTS 侧的 provider 化：同形的单一化确实存在，但本轮只把识别走通。
- 不做识别结果的持久化与审计：是否保存转写原文仍是未决问题。
- 不做 Files API 路径与其远端文件生命周期；第一版只允许 oversize 为 reject。
- 质量谱系（配对实验、语义等价轴）不进判据集，只以 docs/experiments 下的实验记录形式存在。

## 退出条件

- AC-129 线协议实现只有一份，且前端模块、服务端模块、命令行三处都能导入到同一路径。
- AC-130 抽取现有实现后线上字节零变化：入站与两条路径各自的出站请求、以及两条路径各自的响应解析行为，都与改动前基线逐字节一致。
- AC-131 命令行可离线验证：--dry-run 零网络且输出不含密钥与音频字节；--offline 回放产出与录制一致。
- AC-132 能力声明真的生效：超过请求预算的请求返回 OVERSIZE 且上游调用次数为 0（预算含提示词与上下文）；honors 为假的提示参数不出现在请求体中。
- AC-133 MIME 白名单双向且按基类型匹配：带参数的 MIME 与裸基类型都判为受支持，白名单外在上游调用之前被拒。
- AC-134 配置解析：健康检查反映当前用户的有效配置；未注册的 provider id 在三个面都 fail-closed 且不静默回落。
- AC-135 裁剪决策以能力声明为唯一来源，且默认行为不变。

## 不做退出条件的范围内事

- 缺口一与缺口三的服务端侧实现：仅当边界探针走路径 (a) 时成立；若落 (b)，二者退化为「服务端保持现状」，此时相关判据以「服务端不新增 provider」结案。
- 隐私告知的文案与落点：已裁定放设置页，属产品文案范畴。
- 目录纪律（谁能往仓库根 shared/ 放东西）：仅路径 (a) 成立时才需要，登记为长期代价而非判据。
- 联网的「真跑」与需要风格化服务的读数：按 ADR-004 决策 8 归入实验记录，不判据化。

## 已知不等价点与限制

- 路径 (a) 有一项未验证前提：需要 oxlint 的 resolver 能吃下一条新别名；吃不下则落 (b)，该回落已被预先授权。
- 判据不新立任何阈值：引用的 20MB、25MB、10 秒下限等均为既有代码、官方文档或既有实验记录里的既成值。
- 10 秒计费下限未在本机实测，影响对裁剪收益的折算解读，不影响本目标的判据。
- 全部判据跑在 Node 与 Playwright Chromium 下，不等于真机浏览器。
